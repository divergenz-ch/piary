What does HTTP status 418 mean?

<!-- pi -->

HTTP 418 means "I'm a teapot." RFC 2324 defined it in the Hyper Text Coffee Pot Control Protocol, an April Fools' joke from 1998. A teapot returns it when asked to brew coffee. Some servers also use it as a playful response to block or deflect unwanted requests. It isn't meant for real use.
