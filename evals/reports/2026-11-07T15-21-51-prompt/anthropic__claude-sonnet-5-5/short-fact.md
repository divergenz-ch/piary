What does HTTP status 418 mean?

<!-- pi -->

HTTP 418 means **"I'm a teapot."** RFC 2324 defined it in the Hyper Text Coffee Pot Control Protocol, an April Fools' joke. A teapot returns it when it's asked to brew coffee. RFC 7168 later extended the joke to tea-serving devices.

It isn't a real, functional status code. Some servers still use it as an Easter egg. Others use it to deliberately refuse automated requests.
