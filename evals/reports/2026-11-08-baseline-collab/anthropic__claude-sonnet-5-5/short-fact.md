What does HTTP status 418 mean?

<!-- pi -->

HTTP 418 means "I'm a teapot." RFC 2324 defined it as an April Fools' joke, part of the Hyper Text Coffee Pot Control Protocol (HTCPCP). A teapot returns it when asked to brew coffee. Some servers also use it as a joke response or to turn away unwanted requests, but it has no real function in HTTP.
