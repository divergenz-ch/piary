What does HTTP status 418 mean?

<!-- pi -->

HTTP 418 is "I'm a teapot". It comes from RFC 2324, the Hyper Text Coffee Pot Control Protocol, an April Fools' joke from 1998. A teapot returns it when it's asked to brew coffee, because it can't.

Some servers still use it as an Easter egg. Others use it to turn away unwanted requests, such as bots. It isn't meant for real use, and the status code is reserved so that it doesn't get reassigned.
