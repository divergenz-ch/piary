What does HTTP status 418 mean?

<!-- pi -->

HTTP 418 means "I'm a teapot." It comes from RFC 2324, the Hyper Text Coffee Pot Control Protocol, an April Fools' joke from 1998. A teapot returns it when it's asked to brew coffee. The code isn't meant for real use, but some servers return it anyway as an Easter egg. Some also use it to turn away unwanted requests, such as bot traffic.
