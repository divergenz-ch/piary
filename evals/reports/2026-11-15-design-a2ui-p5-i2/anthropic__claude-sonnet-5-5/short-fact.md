What does HTTP status 418 mean?

<!-- pi -->

HTTP 418 means "I'm a teapot." RFC 2324 defined it as an April Fools' joke, as part of the Hyper Text Coffee Pot Control Protocol. A teapot returns it when it's asked to brew coffee, because it can't.

It isn't meant for real use. Some servers still return it as an Easter egg, or to deliberately refuse automated requests.
