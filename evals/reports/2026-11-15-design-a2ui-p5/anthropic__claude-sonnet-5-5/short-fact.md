What does HTTP status 418 mean?

<!-- pi -->

**418 I'm a teapot** is an HTTP status code from RFC 2324, the Hyper Text Coffee Pot Control Protocol. It began as an April Fools' joke in 1998. A teapot returns it when asked to brew coffee, because a teapot can't.

It isn't meant for real use. Some servers still return it on purpose, as an Easter egg or to turn away unwanted requests such as bots.
