What does HTTP status 418 mean?

<!-- pi -->

HTTP 418 means **"I'm a teapot."** RFC 2324 defined it as an April Fools' joke, the Hyper Text Coffee Pot Control Protocol (HTCPCP). A teapot returns it when it is asked to brew coffee, because it can't.

Real servers sometimes use it as an unofficial response. Some use it to refuse a request, for example to block bots. It isn't meant for normal use.
