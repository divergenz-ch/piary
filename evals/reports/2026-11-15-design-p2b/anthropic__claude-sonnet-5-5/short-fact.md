What does HTTP status 418 mean?

<!-- pi -->

**418 I'm a teapot** is an HTTP status code from the April Fools' joke RFC 2324 (Hyper Text Coffee Pot Control Protocol, 1998). It means the server refuses to brew coffee because it is, permanently, a teapot.

It isn't used in real protocol semantics. Some servers return it as an Easter egg, or to deflect unwanted automated requests. RFC 9110 lists it as reserved, so it won't be assigned to anything else.
