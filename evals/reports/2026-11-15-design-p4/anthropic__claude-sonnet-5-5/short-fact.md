What does HTTP status 418 mean?

<!-- pi -->

HTTP 418 means "I'm a teapot." RFC 2324 defined it in the 1998 April Fools' joke protocol, the Hyper Text Coffee Pot Control Protocol. A teapot returns it when it is asked to brew coffee, because it can't.

It isn't used in real HTTP semantics. Some servers return it on purpose as an Easter egg. Others use it to turn away unwanted traffic, such as bots.
