What does HTTP status 418 mean?

<!-- pi -->

**418 I'm a teapot** is an HTTP status code from RFC 2324, the Hyper Text Coffee Pot Control Protocol. It began as an April Fools' joke in 1998. The code means a teapot has been asked to brew coffee and refuses because it is a teapot.

It isn't used for real errors. Some servers return it as an Easter egg, and some use it to turn away unwanted bots or scrapers.
