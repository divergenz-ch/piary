What does HTTP status 418 mean?

<!-- pi -->

HTTP 418 means "I'm a teapot." It comes from RFC 2324, the Hyper Text Coffee Pot Control Protocol, an April Fools' joke from 1998. A teapot returns it when it is asked to brew coffee.

It isn't a real error in practice. Some servers return it as an Easter egg. Others use it to turn away unwanted bots or requests.
