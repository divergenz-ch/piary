What does HTTP status 418 mean?

<!-- pi -->

HTTP 418 means "I'm a teapot." RFC 2324 defined it as an April Fools' joke, as part of the Hyper Text Coffee Pot Control Protocol. A teapot returns it when it's asked to brew coffee. It isn't a real error that servers are expected to handle. Some sites still use it as a joke response, or to turn away unwanted bots.
