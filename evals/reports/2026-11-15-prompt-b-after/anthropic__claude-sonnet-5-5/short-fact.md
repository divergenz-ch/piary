What does HTTP status 418 mean?

<!-- pi -->

HTTP 418 means "I'm a teapot." RFC 2324 defined it in the Hyper Text Coffee Pot Control Protocol, an April Fools' joke from 1998. A teapot returns it when it's asked to brew coffee. Some servers still use it as an Easter egg, and some use it to turn away unwanted bots or requests.
