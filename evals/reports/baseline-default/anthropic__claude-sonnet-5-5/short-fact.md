What does HTTP status 418 mean?

<!-- pi -->

HTTP 418 is "I'm a teapot." RFC 2324 defined it in the Hyper Text Coffee Pot Control Protocol, an April Fools' joke from 1998. A teapot returns it when it's asked to brew coffee, because it can't. RFC 7168 later extended the joke to tea-brewing protocols.

It isn't meant for real use. Some servers still return it on purpose as an Easter egg. Others use it to turn away unwanted traffic such as bots.
