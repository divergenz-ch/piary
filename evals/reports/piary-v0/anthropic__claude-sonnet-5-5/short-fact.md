What does HTTP status 418 mean?

<!-- pi -->

**418 I'm a teapot.** It comes from RFC 2324, the Hyper Text Coffee Pot Control Protocol, an April Fools' joke from 1998. A teapot returns it when it's asked to brew coffee. RFC 7168 later extended the joke to teapots that handle tea requests.

The code isn't meant for real use. Some servers return it on purpose as an Easter egg. Others use it to turn away unwanted automated traffic.
